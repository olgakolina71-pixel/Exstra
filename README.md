# EXSTRA Browser

Android browser project built with Kotlin and Android WebView. The initial foundation includes a URL/search bar, engine switching, navigation, tab management, session persistence, bookmarks, and downloads. More confirmed EXSTRA features will be added incrementally.

## Build APK

Push to `main` or run the **Android APK** workflow from Actions. Download the APK from the workflow artifact.

## Current foundation
- Android WebView browser
- Search engine selection (Google, Bing, Yandex, DuckDuckGo)
- Back / forward / reload
- Tabs and tab switching
- Session restoration
- Bookmarks
- Download manager handoff

Planned: EXSTRA Shield, tab groups, split-screen, vertical tabs, command console, rewind snapshots, skins, data control, modules, extensions, selective VPN, translation, AI search and on-demand page generator.
